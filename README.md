# Planet-Fitness-Portfolio-Project
A Planet Fitness data analysis portfolio project (using a synthetic dataset)

## 📊 Project Overview
This data analytics project explores member retention and gym usage behavior at Planet Fitness using a multi-year synthetic dataset. The goal was to simulate real-world operational challenges faced by a fitness chain and apply data-driven insights to improve member engagement, reduce churn, and optimize resources.

Key components of the project include exploratory analysis, predictive modeling, and behavioral segmentation.

## 🧠 What We Did
- Simulated multi-year data for 1,500 members and over 100,000 gym check-ins to mimic real attendance and membership behaviors across a 24/7 Planet Fitness location.
- Performed retention analysis to identify patterns in member churn, including retention bins by duration and attendance behavior.
- Visualized gym usage trends using heatmaps to reveal high-traffic hours by day of week, and compared usage between Classic and Black Card members.
- Built a churn prediction model using Random Forest, achieving 83% accuracy by analyzing early check-in behavior and demographics.

## ✅ Key Takeaways
- Members who check in frequently during their first 30 days are significantly less likely to churn.
- Gym usage peaks occur consistently on weekdays before and after work hours, with variations between membership types.
- A discount-based incentive model could increase engagement without heavily impacting revenue, especially among low-frequency members.
- Predictive modeling and visual analysis can directly inform staffing, pricing, and retention strategies at scale.
